SUBNAUTICA MULTIPLAYER v{VERSION}

SETUP (once)
1. Run SubnauticaMP-Launcher.exe ("Windows protected your PC"? More info > Run anyway)
2. Top of the Play tab should say "Subnautica: <folder>". If not: Search my PC.
3. Setup tab: no BepInEx? "Install BepInEx for me". Then "Install / update mod".

PLAYING (in the game now, like Nitrox)
- Start Subnautica. Main menu has a new MULTIPLAYER button.
- Servers: your worlds + every server you've joined (saved with the code). Click Join or Host.
- Host a world: name + mode (Survival / Hardcore / Creative / Freedom) > CREATE & HOST.
- Add server: paste your friend's join code > SAVE & JOIN.
- New world: everyone waits on a black screen, host presses ENTER, intro plays for all.
- F8 in game = chat + join code.

No Multiplayer button? Send Subnautica\BepInEx\LogOutput.log
